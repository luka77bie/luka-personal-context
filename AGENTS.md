# Repository instructions

Use the Chinese or English edition as requested. Each edition contains the complete workspace. Begin with [the Chinese reading guide](zh/START_HERE.md) or [the English reading guide](en/START_HERE.md) and the matching edition’s instructions. Choose records relevant to the task, including the target programme’s requirements and status. Read source evidence for material claims and identify the records actually used.

The shared data directory stores stable claim and source IDs, timeline entries and programme status. When approved information changes, update the shared data and both edition records, including translated facts, evidence, timelines and programme trackers. Follow the applicant’s requested editing scope and the current programme rules for assistance, authorship and disclosure. This repository is public. Never add confidential originals, credentials, identity documents, contact records, addresses, private file URLs, confidential application materials or identifying third-party information. Public repository edits are separate from application submission; any submission still requires explicit authorisation.
