# 质量检查

| 检查 | 验收方式 |
| --- | --- |
| 经历归属 | Founder 的实习探索和后续 ETF OOS 独立验证能够分开说明 |
| 模型结论 | Boston housing 仅支持观察性关联；CFA 描述团队原型；ETF 按给定数据、策略设定和 OOS 评价表述 |
| 冲突处理 | Housing 分数、官方学位预测、实习日期、Peer Mentoring 人数与 Cornell 方向能定位到待核实项 |
| 不同题目选材 | Academic、career、setback、community 都能找到证据及对应的使用边界 |
| 个人语气 | 用明确作者和修改状态的样本判断。困难与反思问本人，缺假设时保留空缺 |
| 申请合规 | 核对周期、截止日期时区、题目原文、作者政策、要求和适用资格 |
| 资料维护 | Markdown 相对链接有效、claim 和 story ID 唯一、tracker 与各项目状态吻合。录入前检查个人资料与授权范围 |

实际试跑见 [Cornell 审阅记录](../applications/2027-entry/programmes/cornell-aem/final-checklist.md)。已查看的底稿与本人需确认的内容在那里分开标注。
