## 公开版本与隐私

本仓库为公开的中英双语个人背景与申请工作区。公开内容只包含本人允许整理的脱敏事实、经历摘要、工作稿和核验状态。身份证件、联系方式、住址、账号凭据、原始成绩单、推荐信、第三方资料和私人文件入口不进入公开仓库。
