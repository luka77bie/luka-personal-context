# Graduate Application

Read the owner's START_HERE, the target programme status and requirements, and only the task-specific records and references below. For a programme without a workspace, start from the [cycle instructions](../../applications/2027-entry/index.md). Report actual sources consulted and ask only for material gaps.

| Task | Method |
| --- | --- |
| Select programmes and research fit | [Programme selection](references/programme-selection.md) |
| Verify prompts, deadlines and policy | [Requirements tracker](references/requirements-tracker.md) |
| Choose stories and review a set of essays | [Evidence and essay strategy](references/evidence-and-essay-strategy.md) |
| Adapt CV and prepare recommenders / interviews | [Supporting materials](references/supporting-materials.md) |
| Review before submission | [Final application review](references/final-application-review.md) |

Sequence: scope the application → verify requirements → identify gaps and programme resources → map evidence → allocate stories across materials → review within the permitted authorship scope → check consistency. Formal prose and structure always depend on the programme's stated AI rules. Keep outputs in the relevant programme workspace. Only owner-confirmed information with suitable sourcing can enter the personal facts.
