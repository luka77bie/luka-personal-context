# Requirements tracker

Use the actual application form and official admissions sources for the same entry year, round, mode and track. Record separate statuses for a public requirement and the portal text when both exist. Where they conflict, preserve both and clarify with the programme.

For each item save entry_year, item, prompt_verbatim or portal reference, source_url, source_type, verified_at, deadline/date/timezone, limits, ai_assistance_policy, requirement_status and next_action. Use verified_public, verified_portal, pending_portal, unresolved or conflict. Store long or private prompt text in the applicant's authorised workspace. Public programme summaries may link to full official wording.

Record recommendation type and who submits, testing and waiver requirements, transcript / evaluation requirements, special eligibility, application attestations, and any optional material. Recheck all submission-affecting fields before applying.
