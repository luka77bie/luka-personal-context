# Final application review

1. Reopen the confirmed cycle's prompt and portal requirements. Check exact submission round, time zone, format, word or character count and AI / authorship declarations.
2. Compare date, title, duties, role, results, project status, academic grades, career direction and programme resources across essays, CV, forms and recommender briefing.
3. Identify overstated causality, personal ownership, prototype maturity or live performance. Separate plans and completed work. Flag unsupported claims and record their sources and a next action.
4. Check whether each item contributes distinct evidence or insight. Identify open issues that can change the package and record who must resolve them.
5. Record the approved version and decision. Record submission only on applicant confirmation or actual portal evidence. Preserve the submitted version reference and relevant disclosures.
