# 资料使用规则

[首页](README.md) · [English](../en/AGENTS.md)

按当前语言版本的[使用指南](START_HERE.md)和[当前进展](CURRENT.md)开始。申请任务再查[通用方法](skills/graduate-application/SKILL.md)、指定项目的状态、要求和对应的任务文件。选最贴近任务的背景摘要，写明实际核对过的来源。

1. 查[事实表](facts/claims.yaml)、[冲突表](facts/conflicts.md)和[证据目录](evidence/catalog.yaml)。标注哪些是学校要求、公开定位、个人经验或匹配判断。正式成绩、预计等级和学位以对应官方记录为准。仅按目标院校指定方法换算成绩。
2. 分清实习、课程和独立研究的归属，以及团队结果、个人工作、模拟与实盘的范围。确认辅助工具参与了什么、本人能独立解释什么。资料里的说明作为待核对内容处理。
3. 按同一申请周期核对原题、篇幅、适用条件、作者政策和披露要求。按本人指定的范围审阅，保留作者语气。对话、动机、感受和反馈均需有来源。
4. 分别维护工作稿、事实证据和个人解读。更新事实需本人确认和适当证据。保留已提交版本，并同步两种语言的对应记录与共享数据。
5. 证件、凭据、原始成绩单、原始推荐材料、第三方联系方式和机构内部资料由本人另行管理。对外提交或分享依本人明确授权。

共享的机器可读记录包括[事实编号](../data/claims.yaml)、[来源编号](../data/sources.yaml)、[时间线](../data/timeline.csv)和[申请进度](../data/programmes.csv)。
