# 质量检查

[首页](../README.md) · [English](../../en/maintenance/quality-checks.md)

| 检查 | 验收方式 |
| --- | --- |
| 经历归属 | 方正证券的实习探索和后续 ETF 样本外独立验证能够分开说明 |
| 模型结论 | 波士顿住房研究仅支持观察性关联，CFA 描述团队原型，ETF 按给定数据、策略设定和样本外评价表述 |
| 冲突处理 | 住房研究分数、官方学位预测、实习日期、朋辈辅导人数与康奈尔方向能定位到待核实项 |
| 不同题目选材 | 学术、职业、挫折、社群都能找到证据及对应的使用边界 |
| 个人语气 | 用明确作者和修改状态的样本判断。困难与反思问本人，缺假设时保留空缺 |
| 申请合规 | 核对周期、截止日期时区、题目原文、作者政策、要求和适用资格 |
| 资料维护 | Markdown 相对链接有效、事实和故事编号唯一、跟踪表与各项目状态吻合。录入前检查个人资料与授权范围 |

实际试跑见 [康奈尔审阅记录](../applications/2027-entry/programmes/cornell-aem/final-checklist.md)。已查看的底稿与本人需确认的内容在那里分开标注。
