# 更新流程

[首页](../README.md) · [English](../../en/maintenance/update-protocol.md)

1. 指明目标记录、来源类型、来源位置和发生日期。本仓库公开可见。身份文件、住址、联系方式、登录资料、私人文件入口、原始推荐信及机构内部文件使用仓库外的受控存储。
2. 按 [事实核查](../workflows/fact-check.md) 区分来源类型、核实状态、本人确认和允许用途。用正式记录确认成绩与预测，向本人确认反思和动机。
3. 新信息和现有记录冲突时，先加到 [冲突表](../facts/conflicts.md) 并保留不同口径。本人确认后更新事实表、时间线与引用的经历卡，再刷新依赖它们的背景摘要。
4. 申请的要求、草稿、审阅和已提交版本按具体项目维护。状态由实际材料确认，从考虑中、起草中、已审阅、已认可到提交记录。归档时记录提交日期、版本、渠道及本人确认。
5. 更新 [更新记录](../CHANGELOG.md)。区分事件日期、记录日期和核验日期。旧版可标记或归档，重要事实变更保留修改依据。
