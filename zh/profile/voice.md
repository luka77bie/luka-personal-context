# 写作声音与编辑偏好

[首页](../README.md) · [English](../../en/profile/voice.md)

反馈默认中文，机构、专业、职位和技术术语保留英文。本人希望申请表达接近自己的思考方式，简洁、自然、具体，减少模板化或明显的人工智能语气。优先从一个可描述的决定、结果或场景入手。逐句反馈时注明位置、具体问题和可执行的改法，保留本人的原意。课程或项目事实先核对再个性化；没有依据的主张应标注或收窄，不替它润色成确定事实。按学校政策确定是否可改动结构、措辞或内容。

英语面试练习先从简单问题和两至三句回答开始，逻辑清楚后再逐步增加长度。当前训练重点是临场连接观点、调取词汇和保持表达顺序。WRT-001。

| 样本类别 | 使用方式 |
| --- | --- |
| 本人原始表达 | 作为语气参考，记录场景、日期和本人确认。英文独写样本待本人提供 |
| 人工智能改写、待确认 | 只用于比较和审阅 |
| 本人审阅认可 | 记录认可的具体措辞和场景，注明原始来源和人工智能参与 |
| 顾问建议 | 只用于了解修改意见，记录建议的范围 |
| 其他申请者范例 | 只用于理解题目或体裁，与个人事实、故事及个人语气样本隔离 |

收录格式：样本、语言、用途、作者、人工智能辅助状态、本人确认日期、认可或不喜欢的理由。旧个人陈述、学术目的陈述和推荐人背景材料的作者与编辑痕迹待确认。
