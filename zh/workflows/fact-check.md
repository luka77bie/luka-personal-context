# 事实核查流程

[首页](../README.md) · [English](../../en/workflows/fact-check.md)

1. 给段落中的关键陈述找到事实编号或经历卡，在证据目录分辨是本人陈述、工作稿、官方记录还是可复现结果。
2. 分别核对陈述、来源支持的强度、可引用范围。正式成绩用正式记录，具体工作用可用的证明或交付，个人感受由本人确认。
3. 有冲突则记录双方出处、差别和能解决它的材料。未解决的数字和结论先从正式文本省略。
4. 如核对研究结果，记录运行版本、样本、指标、基准和最多可得出的结论。标明团队与个人贡献。
5. 经本人确认后同步更新事实和时间线。若旧版本已经提交，保留该版本及单独的校正记录。

记录一项事实时分别填写来源类型、核实状态、本人确认和允许用途。若只有来自草稿的素材，记录为内部工作背景。正式对外的关键事实以对应权威来源和本人确认要求为准。
