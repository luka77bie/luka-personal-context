# 研究生申请方法

[首页](../../README.md) · [English](../../../en/skills/graduate-application/SKILL.md)

从[使用指南](../../START_HERE.md)进入。打开目标项目的状态、要求和本次任务涉及的记录。新项目从[入学周期工作区](../../applications/2027-entry/index.md)开始。反馈中写明实际查过哪些来源，只询问会影响当前任务的信息。

| 任务 | 具体方法 |
| --- | --- |
| 选择项目，研究匹配程度 | [选校与项目研究](references/programme-selection.md) |
| 查题目、截止日期和作者政策 | [要求跟踪](references/requirements-tracker.md) |
| 选故事、审阅整套文书 | [证据与文书分工](references/evidence-and-essay-strategy.md) |
| 调整简历、准备推荐人和面试 | [配套材料](references/supporting-materials.md) |
| 递交前核对所有材料 | [最终审阅](references/final-application-review.md) |

先明确申请范围、核对要求，再将学习需求对应到可使用的项目资源。找到支持每道题的证据，安排各篇文书的作用，按学校的作者政策审阅，最后核对整套材料。工作成果放入相应项目。个人事实库只收录本人确认且有适当依据的更新。
