# 简历、推荐人与面试

[首页](../../../README.md) · [English](../../../../en/skills/graduate-application/references/supporting-materials.md)

**简历。** 按学位和篇幅要求取舍。写清日期、职责、工具、结果和证据。交代团队交付与个人承担的部分。涉及辅助工具时，说明实现方式和本人独立验证的内容。

**推荐人。** 根据推荐信类型选择直接观察过相关工作的人。列出其亲眼所见的场景，标明哪些背景来自申请人自述。确认推荐人是否愿意，通过获准的渠道联系。由推荐人执笔、提交。库内记录用途和进度，私人联系方式及原信由本人管理。

**面试。** 每项关键经历各准备一种通俗解释和一种技术解释。追问假设、数据、基准、方法、结果、局限与本人决定。以本人能独立说明为准。实际录制或现场面试遵守项目规则，准备过程中的缺口记在面试页。
