# 证据与文书分工

[首页](../../../README.md) · [English](../../../../en/skills/graduate-application/references/evidence-and-essay-strategy.md)

逐题记录考察点、希望读者了解什么、首选故事及必要的备选故事、本人做出的决定或贡献、事实编号、使用范围和未解决的问题。对话、感受、动机或结果缺少直接记录时，由本人核实。

先通读同一项目的全套文书，再审单篇。标出每篇的作用、重复的事件、结论和情绪变化。一个项目在多篇中出现时，给出各自有依据的侧重点，或另换故事。有特定情况需要说明时再考虑补充文书。

制作提纲、写作、翻译、改写或准备面试辅助材料前，先查该项目的人工智能使用政策。如果只允许讨论选题和检查语法，就标出相关事实、疑问与材料不符处，由本人完成结构与叙述。登记披露要求、当前稿件位置、作者、日期及审阅范围。
