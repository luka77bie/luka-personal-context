# 递交前的最终审阅

[首页](../../../README.md) · [English](../../../../en/skills/graduate-application/references/final-application-review.md)

1. 打开对应入学周期的题目和网申要求，核对轮次、时区、格式、词数或字符数，以及作者声明和人工智能使用披露。
2. 跨文书、简历、网申与推荐人材料，逐项核对日期、职位、职责、结果、项目状态、成绩、职业方向和学校资源。
3. 检查因果推断、个人贡献、原型成熟度或实盘业绩是否超出证据。标清计划与已完成事项。为待核实的主张登记来源和下一步。
4. 核对每份材料带来的新信息。标出会影响整套申请的问题，以及需要由谁确认。
5. 登记本人批准的版本与决定。根据本人确认或网申凭证登记递交情况。保留实际递交版本的位置与相关披露。
