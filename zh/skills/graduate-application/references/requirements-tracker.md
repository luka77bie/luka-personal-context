# 申请要求跟踪

[首页](../../../README.md) · [English](../../../../en/skills/graduate-application/references/requirements-tracker.md)

根据同一入学年、轮次、授课方式和方向的网申及官方说明填写。分别登记官网公开要求和网申题目。两者有差别时保留原出处，向项目核实。

每项记录入学年、项目、题目原文或网申位置、来源网址和类型、核对日期、截止时间和时区、篇幅、人工智能辅助政策、核对状态与下一步。状态包括官网已核对、网申已核对、网申待核对、未解决和存在冲突。长篇或非公开题目放在本人授权的位置。公开题意可链接学校原文。

另记推荐信的类型和递交人、考试及豁免、成绩单与认证、特殊资格、申请声明及选交材料。递交前重新核对会影响提交的字段。
