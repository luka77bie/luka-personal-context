# 选校与项目研究

[首页](../../../README.md) · [English](../../../../en/skills/graduate-application/references/programme-selection.md)

1. 记录入学年份、学位、授课方式、专业方向、地点、学制、预算及尚未决定的条件。区分当前目标、正在探索的兴趣与长期可能方向。
2. 从一段已有经历出发，写清要补哪项能力，哪项课程或实践资源可用，准备用它做什么，以及与下一步职业计划的联系。核对学位、入学年级和方向是否有资格选课或参加活动。
3. 分别标记官方要求、项目公开定位、个人经验和匹配判断。录取要求以官方指引为准。学生经历可以提供进一步核实的线索。
4. 保留原成绩制。仅按目标院校明确指定的方法换算。给已核实的信息注明日期、来源，按课程、学制与资源准入等具体差别比较。
5. 写出附来源的匹配笔记、资格和资源方面的待查项，以及本人的选择。本人确认前，项目状态记作考虑中。
