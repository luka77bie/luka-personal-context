# 成绩与学位口径

| 字段 | 当前记录 | 对外使用条件 |
| --- | --- | --- |
| 已取得成绩 | UK percentage scale。大二均分及已知课程分数见 EDU-002 | 对照相应版本的正式成绩单，保留重考和学年口径 |
| 本人目标或预估 | 新版设计笔记记录旧中文 CV 的个人预估为 First-Class | 本人确认后，按个人预估表达 |
| 学校正式预测 | 英文 CV、Advisor Packet 写 expected 2:1，学校是否正式签发预测待核实 | 以学校正式出具的记录为准 |
| 最终学位结果 | 学位尚未完成，结果待记录 | 以最终 transcript 或 degree record 为准 |

使用对方明确规定的换算方法才单独记录 GPA 换算及出处。住房项目分数和学习记录的细项见 [冲突表](conflicts.md)。
