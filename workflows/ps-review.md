# PS / SOP 修改流程

1. 定义任务。拿到项目、入学年份、题目、草稿和本人希望反馈的范围。看对应 brief，并按需核验最新官方要求。记录哪些材料实际看过。
2. 确认帮助边界。若学校要求本人独立构思结构与写作，保留本人的结构。可在允许范围内问素材问题、检查事实或标出词句问题。按要求提示披露。
3. 对照事实。读相关经历卡、claims 和 conflicts。检查角色、日期、结果边界与可使用范围。把对结论有影响的缺口明确留给本人。
4. 在允许范围内反馈。说明问题和出处，有针对性地给修改建议。若可实质改写，逐段追踪新增、删改的事实。需要本人写的地方用问题帮助他推进。
5. 完成前检查题意、字数、语气、因果表述、具体项目匹配和信息归属。
6. 交付包括实际读取材料、优先问题、允许范围内的反馈、改动依据和需本人确认的事项。由本人批准和提交。

调用示例：`请读取 AGENTS.md、START_HERE.md 和对应 brief，按该项目允许的范围审阅我贴出的文书。优先核对与题目的匹配、事实和我的个人语气。`
